# SIMS ERP – نظام تخطيط موارد متكامل

**SIMS** هو نظام ERP متقدم مبني على `Next.js` و `Prisma` و `PostgreSQL`، صُمم خصيصاً لإدارة الشركات متعددة الفروع، ويشمل وحدات المحاسبة، المخزون، نقاط البيع، الجرد، طلبات التوصيل، التحقق من الهوية (KYC)، الذكاء الاصطناعي، والترجمة الفورية بين العربية والإنجليزية.

---

## 🚀 الميزات الرئيسية

- **إدارة المخزون**: تتبع المنتجات بالباركود، تجزئة بلوكشين، حركات دخول/خروج، جرد كامل/جزئي/عشوائي مع تسوية محاسبية تلقائية.
- **نقطة البيع (POS)**: بحث سريع، سلة مشتريات، طرق دفع متعددة (كاش، بطاقة، آجل)، طباعة فاتورة بـ QR Code، طلب توصيل مع خريطة تفاعلية.
- **المحاسبة**: دليل حسابات هرمي، قيود يومية متوازنة، قيود البيع والشراء والتسوية، تقارير مالية.
- **التوثيق (KYC)**: رفع صورة جواز السفر، التقاط سيلفي، مطابقة الوجه باستخدام `face-api.js`، استخراج بيانات النص من الصور باستخدام `Tesseract.js`.
- **الذكاء الاصطناعي**: شات مدمج بسياق بيانات الشركة، تحليل تنبؤي للمبيعات والمنتجات الراكدة.
- **الشركاء التجاريون**: طلب مخزون بين الشركات المتعاونة.
- **التوصيل**: إدارة السائقين، توزيع الطلبات لأقرب سائق متاح.
- **الصلاحيات**: أدوار متعددة (مدير النظام، مدير فرع، صراف، محاسب) مع تحكم دقيق بالمسارات.
- **الوضع المظلم والترجمة**: دعم ثنائي اللغة (عربي/إنجليزي) مع تبديل ديناميكي للغة والاتجاه.

---

## 🛠️ المتطلبات التقنية

- **Node.js** v18 أو أحدث.
- **PostgreSQL** (يُفضل استخدام Neon أو Supabase للحصول على قاعدة بيانات سحابية).
- حساب **Resend** لإرسال رموز OTP عبر البريد الإلكتروني.
- **مفتاح OpenAI** (اختياري، للدردشة والتنبؤ الذكي).
- **مفتاح Google Maps** (اختياري، لعرض الخرائط وتحديد مواقع التوصيل).

## 📦 التثبيت والتشغيل

```bash
# 1. استنساخ المستودع
git clone <repository-url>
cd sims

# 2. تثبيت الاعتماديات
npm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# ثم افتح ملف .env واملأ القيم المطلوبة (قاعدة البيانات، المفاتيح، إلخ)

# 4. إنشاء قاعدة البيانات وتطبيق النماذج
npx prisma generate
npx prisma db push   # أو npx prisma migrate dev --name init

# 5. تشغيل بذور البيانات (Seed)
npm run seed         # سينشئ دليل الحسابات، مدير النظام، و6 شركات تجريبية
# 6. تشغيل التطبيق في وضع التطوير
npm run dev
